# Mega Burger — Cardápio Digital

Projeto demonstrativo de um cardápio digital responsivo feito com HTML, CSS e JavaScript.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Como personalizar
- Para trocar o nome, procure por `Mega Burger` no arquivo `index.html` e substitua pelo nome da lanchonete.
- Para configurar o WhatsApp, procure pela variável `WHATSAPP` no JavaScript e informe o número com código do país e DDD, somente números. Exemplo: `5511999999999`.
- Edite os produtos, preços e descrições no próprio `index.html`.

## Publicar pelo GitHub
1. Entre em https://github.com e faça login.
2. Clique em **New repository**.
3. Dê um nome ao repositório, por exemplo `cardapio-mega-burger`.
4. Escolha **Public** ou **Private** e clique em **Create repository**.
5. Na página do repositório, clique em **Add file** → **Upload files**.
6. Extraia este ZIP no computador e arraste os arquivos e pastas que estão dentro da pasta do projeto para a área de upload do GitHub. Envie `index.html`, `README.md` e `.gitignore` (não envie o arquivo ZIP).
7. Clique em **Commit changes**.

## Publicar o site gratuitamente com GitHub Pages
1. No repositório, abra **Settings**.
2. No menu lateral, entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`.
5. Clique em **Save** e aguarde a publicação.
6. O GitHub mostrará o endereço do site na própria página de Pages.

> Observação: este é um cardápio demonstrativo. Antes de usar com clientes, troque o nome, os produtos, os preços e configure o número real de WhatsApp.
